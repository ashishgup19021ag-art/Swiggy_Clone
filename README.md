# Swiggy Clone (Food-Rush)

A responsive food delivery web application inspired by Swiggy, built with **React and Vite**.

## 🚀 Live Demo

👉 [View Food-Rush Live](https://food-dillivery.netlify.app/)

## 👨‍💻 About the Project

Food-Rush is a Swiggy-inspired food delivery application developed by **Ashish Gupta**. The project demonstrates modern React development, responsive UI design, and state management using Redux Toolkit.

## 🛠️ Tech Stack

- **Frontend:** React, Vite
- **State Management:** Redux Toolkit

## ✨ Features

- 🍔 Restaurant and food listings
- 🔍 Search functionality
- 🛒 Shopping cart
- ➕ Add and remove food items
- 📱 Responsive design
- ⚡ Dynamic UI
- 🔄 Redux state management
